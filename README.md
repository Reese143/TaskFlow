# TaskFlow

Демонстрационное приложение для управления задачами: FastAPI + SQLite + HTML/CSS/JavaScript.

## Возможности

- CRUD для задач через REST API
- Список задач, статистика, поиск, фильтры и приоритеты
- Светлая и тёмная тема
- Четыре акцентных цвета
- Компактное отображение задач
- Режим фокуса (скрывает выполненные задачи в интерфейсе)
- Сохранение предпочтений в `localStorage` текущего браузера
- Адаптивный дизайн

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
