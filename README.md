# TaskFlow

Демонстрационное приложение для управления задачами: FastAPI + SQLite + HTML/CSS/JavaScript.

## Возможности

- CRUD для задач через REST API
- Список задач, статистика, поиск, фильтры и приоритеты
- Светлая и тёмная тема
- Четыре акцентных цвета
- Компактное отображение задач
- Режим фокуса (скрывает выполненные задачи в интерфейсе)
- Сохранение предпочтений в `localStorage` текущего браузера
- Адаптивный дизайн

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Открой http://127.0.0.1:8000. Документация API: http://127.0.0.1:8000/docs.

## Примечания

Задачи хранятся в `taskflow.db`. Настройки интерфейса хранятся локально в браузере и не синхронизируются между устройствами. Приложение демонстрационное, без регистрации и отдельных пользовательских аккаунтов. Не публикуй его как открытый многопользовательский сервис без авторизации и дополнительных ограничений.
